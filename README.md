# Collabor8 website

**Live site:** http://collabor8.solutions (secure https address coming once GitHub issues the certificate)

Static site. Pages live in `site/` and are generated by `tools/build.py` from `tools/pages/`.

- Build: `python3 tools/build.py`
- Local preview: `cd site && python3 -m http.server 8000`
- Publish: push to `main`; GitHub Pages deploys `site/` (Netlify retired 7 Nov 2026).
