# Collabor8 website

Static site. Pages live in `site/` and are generated by `tools/build.py`.

- Build: `python3 tools/build.py`
- Local preview: `cd site && python3 -m http.server 8000`
- Publish: see PROJECT.md (main auto-deploys to Netlify; previews via `netlify deploy --dir site` without `--prod`).
