# Project card: Collabor8 website

**What it is:** The Collabor8 company website, a senior advisory firm site for chief executives, strategy leaders, founders and investors. Single action: Book a call. **Status: Phase 1 live on main since 2026-10-13 (approved by Lee).**

**Repo:** https://github.com/leepurcell-cpu/collabor8-website (private). `main` = production. `phase1-preview` = Phase 1 build for review.

**Hosting:** Netlify, free plan. Site name `zesty-daffodil-39a0bd` (auto-named), site ID `4a1bcbc8-856a-4ebd-a376-71ae754c7524`, live at https://zesty-daffodil-39a0bd.netlify.app (no custom domain). Linked to GitHub via Netlify GitHub app (installation 170879298), branch `main`, publish dir `site`, no build command. Only `main` auto-builds.

**Stack:** Plain static HTML/CSS/JS in `site/`. Pages are generated by `tools/build.py` (shared header/footer); edit copy there and run `python3 tools/build.py`. Inter is self-hosted from @fontsource/inter 5.3.0 in `site/fonts/` (latin + latin-ext, 400/500/600). No CDN fonts.

**How to publish:**
1. Edit `tools/build.py` (or CSS/JS in `site/assets/`), run `python3 tools/build.py`, bump `VER` for cache busting.
2. Preview: `bash -lc 'npx netlify-cli deploy --dir site --site 4a1bcbc8-856a-4ebd-a376-71ae754c7524 --message "..."'` (draft, not production). Auth via NETLIFY_AUTH_TOKEN env var.
3. Go live (only after Lee's yes): merge `phase1-preview` into `main` and push. Netlify deploys automatically.
4. Check the live URL at 1440 and 390 widths, then add a build log line below.

**Quirks and gotchas:**
- Brand accent #1482B8 fails WCAG AA with white text (4.27:1) and as link text on #FAFAF7 (4.09:1). Buttons and links use #137AAD (4.76:1 on white, 4.55:1 on #FAFAF7). #1482B8 is kept for decorative rules and step markers only.
- Linked pages are indexable. Hidden stubs (Services, Sectors and markets, Insights, About) carry noindex (`noindex=True` in build.py), are unlinked and not in the sitemap.
- `BASE` in `tools/build.py` and the URL in `site/robots.txt` point to the netlify.app URL; change to the real domain at launch (canonical, OG, sitemap).
- Text in square brackets renders as highlighted placeholders (`.ph`). None may go live.
- Book a call links are mailto:lee.purcell@collabor8.solutions?subject=Book%20a%20call (`BOOK` in build.py).
- Cookie gate: non-essential scripts must be added as `<script type="text/plain" data-consent="analytics" data-src="...">`; they run only after Accept. Decline keeps them off. Choice stored in localStorage `c8_consent`; `c8Consent.reset()` clears it.
- Netlify site creation with a custom name returned 422 earlier; auto-named site works.
